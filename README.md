# Simon Says - STD Project

Веб-застосунок для гри Simon Says, розроблений у рамках навчальної дисципліни Стандартизація та документування ПЗ.

## Автор
- Студент: Отовчиць Ілля
- Група: ІПЗ 23-4
- Університет: Державний університет «Житомирська політехніка»

---

## Базові команди

Для запуску та розробки проекту використовуйте наступні команди:

 npm install - Встановлення всіх необхідних залежностей 
 npm run dev - Запуск локального сервера розробки Vite
 npm run storybook - Запуск середовища Storybook для перегляду компонентів 
 npm run docs - Генерація технічної документації проекту через JSDoc 
 npm run build - Збірка проекту для продакшну 

---

## Конфігурація та Технології
Проект налаштований з використанням сучасного стеку та інструментів стандартизації:
- Framework: React + Vite
- Storybook: Налаштовані історії для базових Button та комплексних Header компонентів.
- JSDoc: Конфігурація через jsdoc.json для автоматичного створення папки docs/.
- GDPR: Інтегровано банер згоди через react-cookie-consent.
